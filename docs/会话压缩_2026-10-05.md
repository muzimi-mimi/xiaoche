## 3. 🔴 我在压缩时复核磁盘，发现三个当前真实存在的问题

这几个是**本次复核新发现**的，不在原会话里：

### 3.1 `CCD_Div = 1.5` 被整数类型吃掉了

`Core/Src/ccd.c:63`
```c
volatile uint16_t CCD_Div = 1.5;   /* 初始 3 x 10ms = 30ms */
```
`uint16_t` 赋 `1.5` → **截断成 1**。
注释写的是"初始 3"，说明**有人把 3 改成了 1.5**（大概想要 15 ms 的精细控制），但整数类型把它变成了 1。

**实际效果**：`CCD_Div = 1` → `HAL_TIM_PeriodElapsedCallback` 每次中断都发 SI → **曝光固定 10 ms** → 画面偏暗。
这很可能正是"白纸只有十几"的直接原因之一。

> 要 15 ms 应该写 `CCD_Div = 1.5f` 并把类型改成 `float`，或者干脆保持整数：`CCD_Div = 2`（20 ms）。

### 3.2 自动曝光被注释掉了

`Core/Src/main.c:73`
